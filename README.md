# Family Finance Analysis

This is a personal project where I’m using my own household finances to practice data analysis and get more comfortable working with real-world data.

I wanted to start with something that is actually useful to me rather than working with a random dataset. The project will grow as I learn new tools and techniques.

## What I’m working on

For now, I’m starting with Excel and focusing on:

- Organising and cleaning financial data
- Categorising income and expenses
- Looking at spending patterns
- Comparing expenses over time
- Creating simple visualisations
- Finding useful insights from the data

## Current tools

- Excel
- Git
- GitHub

More tools may be added as the project develops.
